Project Overview

The Bright Coffee Shop Sales Analysis project focuses on analysing historical sales transaction data to help the business understand its sales performance and identify opportunities to increase revenue.

The project was assigned as part of the BrightLearn Case Study 1, where the objective is to use data analytics, SQL, and data visualisation to generate actionable insights for the company's new CEO.

The analysis aims to identify the products that generate the most revenue, determine the best-performing time intervals, evaluate product sales trends, and recommend strategies to improve overall business performance.

Process
Data Preparation: Convert Excel data to CSV and clean the dataset using Databricks.
Data Transformation: Standardise prices, create time intervals, and calculate total revenue.
SQL Analysis: Analyse revenue, quantities sold, and product performance.
Visualisation: Use charts, pivot tables, and dashboards to communicate insights.
Recommendations: Suggest strategies to improve sales and support business decisions.

Tools Used
SQL: Data querying and analysis.
Databricks: Data cleaning and transformation.
Microsoft Excel: Pivot tables and charts.
Power BI: Dashboard development.
Miro: Data flow and architecture planning.
GitHub: Project documentation and version control.

Summary

This project demonstrates how SQL, data processing, and visualisation can be used to understand sales performance, identify business opportunities, and support data-driven decision-making.
